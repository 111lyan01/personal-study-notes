You can prompt the user to give a string, integer, float, or boolean value with a message like such:

```js
CODE
──────────────────────
var name = readLine("What is your name?"); // user will input a STRING
var num = readInt("Put some number here!"); // user will input an INTEGER
println(name);
println(num);

CONSOLE
──────────────────────
What is your name?[user inputted value: Ana]
Put some number here![user inputted value: 4]
Ana
4
```
