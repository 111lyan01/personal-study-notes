Variables can assign a integer, float, string, or boolean value to an object.

>[!NOTE] Example
>```js
>var apples = 20;
>var oranges = 15;
>println("apples = " + apples);
>println("oranges = " + oranges);
>oranges = 0;
>println("apples = " + apples);
>println("oranges = " + oranges);
>
>──CONSOLE─────────────────────────────────────────────────
>// outputs
>```
