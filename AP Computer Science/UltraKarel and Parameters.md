UltraKarel has a new conditional and function:
```js
// Function
paint(color);

// Conditional
(isColor(color))
(colorIsNot(color))

// (color) parameter options
Color.red
Color.blue
Color.green
Color.yellow
Color.cyan
Color.orange
Color.white
Color.black
Color.gray
Color.purple
Color.random
```

Parameters are inputs that go in the parenthesis `()` of a function. The `paint` function so far is the only function that supports and requires a parameter, being `color`. To paint the area that Karel is standing on to blue, you can use the command `paint(Color.blue);`, which uses the paramter inside the parenthesis.
