Super Karel has the following commands built in:
```js
turnRight();
turnAround();
```

It also has the conditionals built in:
```js
frontIsClear()
leftIsClear()
rightIsClear()

facingNorth()
facingSouth()
facingEast()
facingWest()

notFacingNorth()
notFacingSouth()
notFacingEast()
notFacingWest()

ballsPresent()
noBallsPresent()
```
