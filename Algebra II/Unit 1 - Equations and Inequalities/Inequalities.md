## Interval Notation and Set Notation
Use parenthesis for not including numbers, use brackets for included numbers in interval notation.

>[!NOTE] Interval Notation
>$x \gt 2 = (2, \infty)$
>$x \leq -6 = (-\infty, -6]$

>[!NOTE] Set Notation
>$x \lt -4 = \{x|x \lt -4\}$
>$x \ge 3 = \{x|x \ge 3\}$
>$4 = 4 = \{x|x \in \mathbb{R}\}$
>$-4 \leq -3 = \{x|x \in \mathbb{R}\}$
