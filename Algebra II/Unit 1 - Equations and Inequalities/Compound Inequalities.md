# Standard Cases
## "Or" Inequalities
Solve each part then graph on a number line

>[!NOTE] Example
>$$-3y+8 \leq -7 \space \mathtt{or} \space 10y -3 \leq -33$$
>$-3y \leq -15$ or $10 \leq -30$
>$y \ge 5$ or $y \leq -3$
>Interval Notation: $(-\infty, -3]\cup[5, \infty)$
## "And" Inequalities
If "and" is shown in the equation, solve separately. If it's more like $\mathtt{[num]}\lt x \lt \mathtt{[num]}$ then work inside out altogether.

>[!NOTE] Examples
>$$2w + 1 \leq 11 \space \mathtt{and} \space 1 - 5w \lt 41$$
>$2w \leq 10$ and $-5w \lt 40$
>$w \leq 5$ and $w \gt -8$
>Interval Notation: $(-8, 5]$
>
>$$-5 \leq \frac{12-x}{-2}\lt -2$$
>$10 \ge 12 -x \gt 4$
>$-2 \ge -x \gt -8$
>$2 \leq x \lt 8$
>Interval Notation: $[2, 8)$

>[!WARNING] Special Cases
>If the equation is a "and" equation and the number line is like
>```
><-----------o              o--------------------->
><=================================================>
>```
>The interval notation is $\varnothing$
>
>If the equation is a "and" equation and the number line is like
>```
>               o---------------------->
>       <------------------------o
><=================================================>
>```
>The interval notation is of the points that span to each other
>
>If the equation is a "and" equation and the number line is like
>```
><-------------------------------o
><-----------------o
><=================================================>
>```
>The interval notation is of the point closest to the shared infinity side
>
>If the equation is an "or" equation and the number line is like
>```
>                       o--------------------------->
>                o---------------------------------->
><=================================================>
>```
>The interval notation is of the point farthest from the shared infinity side
>
>If the equation is an "or" equation and the number line is like
>```
><----------------------------------o
>             o------------------------------------->
><=================================================>
>```
>The interval notation is $(-\infty, \infty)$
