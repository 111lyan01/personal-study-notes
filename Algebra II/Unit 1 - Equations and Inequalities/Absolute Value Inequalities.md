1. Isolate absolute value expression
2. Create two cases using keep it, switch switch
3. Solve both
4. Graph and write in interval notation

>[!NOTE] Example
>$$9|3-k|-5 \ge 67$$
>$3-k \ge 8$ or $3-k \leq -8$
>$k \leq -5$ or $k \ge 11$
>Graph:
>```
><-------*                   *------>
><===8====4====0====4====8====12====>
>neg           |                  pos
>```
>Interval Notation: $(-\infty, -5)\cup[11, \infty)$
