**Real Numbers** ($\mathbb{R}$) consist of the following

| Set                | Latter | Examples                                                                  |
| ------------------ | ------ | ------------------------------------------------------------------------- |
| Irrational Numbers | I      | $\pi, \space \sqrt{2}, \space \sqrt{72}, \space e, ...$                   |
| Rational Numbers   | Q      | $\frac{2}{3}, \space -2.5, \space 0.6..., \space -\frac{7}{10}, \space 1$ |
| Integers           | Z      | $-5, -2, 0, 13, 42, ...$                                                  |
| Whole Numbers      | W      | $0, 1, 2, 3, ...$                                                         |
| Natural Numbers    | N      | $1, 2, 3, ...$                                                            |
