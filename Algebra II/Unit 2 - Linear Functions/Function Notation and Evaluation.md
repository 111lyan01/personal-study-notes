Function notation looks like this:
$$y=2x+7 \rightarrow f(x)=2x+7$$
>[!note] Evaluating Functions
>Simply substitute the value that is defined for the given function.
>Given $f(x)=-5x-14$, evaluate if $f(-9)$
>$$-5(-9)-14$$
>$= 45-14$
>$= 31$
>
>Given $g(x)=-x^2+9x-1$, evaluate if $2[g(12)]$
>$$2\big( -(12)^2+9(12)-1 \big)$$
>$= 2(-144+108-1)$
>$= 2(-37)$
>$= -74$
>
>Given $g(x)=x^2-5$ and $f(x)-4x+9$ evaluate the following: $g(2m+1)-f(3m-7)$
>$$\big( (2m +1)(2m+1)-5 \big) - \big( -4(3m-7)+9 \big)$$
>$= (4m^2+2m+2m+1-5)-(-12m+28+9)$
>$= 4m^2+4m-4 + 12m-28-9$
>$= 4m^2+16m-41$
