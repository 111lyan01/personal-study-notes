Relations can be shown on a **table**, **mapping**, **graph**, or expressed as an **equation**.
The set of x values is the **domain**
The set of y values is the **range**
A relation with distinct points is the **discrete**
A relation with connected lines/curves is the **continuous**
## Functions
Functions are relations in which each element of the domain is paired with one element of the range. This means that **domain values cannot repeat!**

>[!NOTE] Example
>This is a **function**.
>$$\{(0,1), (-5,2), (6,-2)\}$$
>This is **not a function!**
>$$\{(7,3), (6,4), (7,4), (9,3)\}$$

>[!NOTE] The Vertical Line Test
>One a graph, the function cannot have any two points that are on the same x position, which can be tested with a vertical line to see if it intersects two points or two lines.

>[!note] Examples
>$$\{(-1,-9), (0,-5), (4,3), (6,-2)\}$$
>D: $-1, 0, 4, 6$
>R: $-9, -5, -2, 3$
>
>```

>│ y │ -8│ 3 │ -1│ 3 │
>└───┴───┴───┴───┴───┘
>```
>D: $-4,0,2,7$
>R: $-8,-1,3,3$
>
>```
>-4---> 0
>

>
>5----> 1

>```
>D: $-4,-2,5,8$
>R: $0,1,2,4$
