## Conversion Ladder
To convert to a **smaller unit**, move the decimal point to the **right**.
To convert to a **larger unit**, move the decimal point to the **left**.

| Unit           | Amount relative to meters |
| -------------- | ------------------------- |
| Quetta-        | 1 Qm = 10<sup>30</sup>m   |
| Ronna-         | 1 Rm = 10<sup>27</sup>m   |
| Yotta-         | 1 Ym = 10<sup>24</sup>m   |
| Zeta-          | 1 Zm = 10<sup>21</sup>m   |
| Exa-           | 1 Em = 10<sup>18</sup>m   |
| Peta-          | 1 Pm = 10<sup>15</sup>m   |
| Tera-          | 1 Tm = 10<sup>12</sup>m   |
| Giga-          | 1 Gm = 10<sup>9</sup>m    |
| Mega-          | 1 Mm = 1,000,000m         |
| **Kilo-**      | **1 km = 1,000m**         |
| Hecto-         | 1 hm = 100m               |
| Deca-          | 1 dam = 10m               |
| **Basic Unit** | **1m = 1m**               |
| Deci-          | 1 dm = 0.1m               |
| **Centi-**     | **1 cm = 0.01m**          |
| **Milli-**     | **1 mm = 0.001m**         |
| Micro-         | 1 $\micro$m = 0.000001m   |
| Nano-          | 1 nm = 10<sup>-9</sup>m   |
| Pico-          | 1 pm = 10<sup>-12</sup>m  |
| Femto-         | 1 fm = 10<sup>-15</sup>m  |
| Atto-          | 1 am = 10<sup>-18</sup>m  |
| Zempto-        | 1 zm = 10<sup>-21</sup>m  |
| Yocto-         | 1 ym = 10<sup>-24</sup>m  |
| Ronto-         | 1 rm = 10<sup>-27</sup>m  |
| Quecto-        | 1 qm = 10<sup>-30</sup>m  |
